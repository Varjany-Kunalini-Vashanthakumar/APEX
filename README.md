# APEX — Action Potential Examination Platform

**Advanced Cardiac Electrophysiology Analysis Suite**

APEX is a Python-based tool for automated analysis of action potentials (APs) from cardiac electrophysiology recordings. It supports multiple species (rabbit, mouse, zebrafish, cardioid) and file formats (ABF, CSV, Excel).
